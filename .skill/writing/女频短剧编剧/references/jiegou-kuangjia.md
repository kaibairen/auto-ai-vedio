# 结构框架

> 本文档覆盖：女频四幕骨架 → 单集公式 → 情绪节拍 → 付费卡点 → 各赛道专属阶段结构表。

---

## 1. 通用结构骨架（女频四幕）

女频通用四幕：**绝境铺垫 → 逆袭起步 → 高潮爆发 → 圆满收尾**（抑—扬—爽—合）

| 幕 | 作用 | 大致占比 |
|----|------|----------|
| 绝境铺垫（抑） | 开篇即高潮展最惨时刻+埋逆袭伏笔 | ~15% |
| 逆袭起步（扬） | 女主觉醒、立足、首次反击 | ~30% |
| 高潮爆发（爽） | 身份曝光、核心打脸、终极对决 | ~35% |
| 圆满收尾（合） | 清理隐患、情感落地、价值升华 | ~20% |

> **女频专属：高潮前置**——将最炸裂的爽点（身份曝光、打脸名场面）放在剧集前半段，提升完播率，为系列化铺垫。这是女频区别于男频的关键节奏。

## 2. 单集万能公式（约1-3分钟）

```
3秒钩子 → 核心冲突 → 爽点输出 → 结尾钩子
```

| 节拍 | 时长 | 内容 |
|------|------|------|
| 钩子 | 0-3秒 | 情绪特写/嚣张台词/突发冲突 |
| 核心冲突 | 3-60秒 | 反派挑衅、阴谋实施、女主陷困境 |
| 爽点输出 | 60-120秒 | 女主反击、打脸、技能/身份展示 |
| 结尾钩子 | 120-180秒 | 反派放狠话、新人物登场、线索曝光、暧昧互动 |

---

## 3. 情绪循环节拍

```
压抑 → 释放 → 再压抑 → 再释放（螺旋上升，一次比一次解气）
```

节奏要求：
- 每次释放的力度比上次大
- 两次释放之间留"喘气"间隙（萌宝互动/温馨日常/感情升温）
- 大高潮前压到极值

---

## 4. 付费点设计原则

- 卡点设在情绪最高/悬念最强处
- 每个付费段落自带一次爽点或情感转折
- 大爽点前设钩子，诱导继续
- 配合高潮前置：前半段的身份曝光/打脸名场面本身就是强付费点
- 女频特殊：情感转折点（误会初现松动、男主坦白真相）也是高付费转化位

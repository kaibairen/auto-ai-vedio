# 女频短剧编剧 Skill

## 用途
- **输入**：一个原创需求，或一部待判定的小说/设定
- **输出**：型判定 → 赛道选择 → 分阶段剧情大纲 + 审稿清单
- **不负责**：成稿正文、逐场台词。台词模板是"零件"，不是成品。

> 天花板是"分集大纲/桥段"层。女频尤其注意：不要被"爽点密集"带偏成空洞打脸，情感线与自我成长内核是女频的命根子。

---

## 使用流程

```
输入需求 → 型判定 → 赛道定位 → 读对应 references 章节 → 套结构生成大纲 → 过审稿清单
```

### Step 1：读需求或原著特征
提取女主起点、核心能力/金手指、情感线定位、冲突类型。

### Step 2：型判定
用 `references/ticai-yurenshe.md` 第1节的**型判定表**，归入：
- **实力逆袭型** — 看点：靠本事翻身（职场/学霸/神医/修仙穿越）
- **身份反转型** — 看点：何时亮隐藏身份/背景（真千金/马甲/玄幻大女主）
- **情感关系型** — 看点：情感如何拉扯/清算（虐恋/甜宠/破镜重圆/婚恋复仇）

判定口诀：*"看她怎么靠本事翻身"→实力逆袭型；"看她何时亮身份/背景"→身份反转型；"看两人怎么走到一起/如何清算感情"→情感关系型。*

> 混血提示：不少女频剧跨型（如马甲+先婚后爱、真千金+双向奔赴）。判定取"最核心看点"归主型，另一型在赛道展开里标注参考。

### Step 3：赛道定位
查 `references/ticai-yurenshe.md` 第2-3节**赛道细分+路由表**，锁定具体赛道。

### Step 4：读取 references 对应章节

| 需求 | 读取文件 | 定位章节 |
|------|---------|---------|
| 人设/金手指/反派设计 | `ticai-yurenshe.md` | 该型→该赛道的展开节 |
| 阶段结构/集数体量/单集节奏 | `jiegou-kuangjia.md` | 该型→该赛道的专属结构表 |
| 爽点类型/付费卡点/节奏编排 | `shuangdian-sheji.md` | 该型→该赛道的爽点配置 |
| 审稿口诀/反面清单/命门校验 | `luoji-jiaoyan-qingdan.md` | 通用清单 + 型清单 + 赛道清单 |

### Step 5：套结构生成大纲
按该赛道的专属结构表（`jiegou-kuangjia.md`）填充分阶段大纲，标注爽点位置和付费卡点。

### Step 6：过审稿清单
按 `luoji-jiaoyan-qingdan.md` 的**五层自检**：通用清单 → 型审稿口诀 → 型级清单 → 赛道反面清单 → 命门校验。

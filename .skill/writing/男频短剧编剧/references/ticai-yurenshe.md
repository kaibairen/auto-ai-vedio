# 题材与人设

> 本文档覆盖：型判定 → 皮肤映射 → 赛道选择 → 选题生成 → 各赛道完整人设模板。

---

## 1. 型判定表（先判型）

| 特征 | 成长型 | 身份型 | 预知型 |
|------|--------|--------|--------|
| 主角起点 | 弱小/落魄，实力低 | 已是巅峰，隐藏实力 | 可高可低，起点非重点 |
| 核心看点 | 变强曲线（怎么变强） | 揭晓时机（何时亮身份） | 信息差（预知如何兑现与递减） |
| 时间结构 | 由弱到强，循序渐进 | 开局即巅峰，扮猪吃虎 | 与"已知的坏结局"赛跑、改写命运 |
| 爽感来源 | 越级战、突破、逆袭 | 反差打脸、身份曝光 | 认知碾压、改写既定悲剧 |
| 成长写法 | **必须有依据** | **不写成长/不适用成长依据** | **不靠成长/靠信息，信息优势须递减** |
| 代表赛道 | 逆袭·修仙·玄幻 | 战神·赘婿·霸总 | 重生·穿越 |

判定口诀：**"看他怎么变强"→成长型；"看他何时亮身份"→身份型；"看他怎么用预知改命"→预知型。**

## 2. 皮肤/场景映射表（热门叫法不单独建模）

| 常见叫法 | 本质归属 | 操作指引 |
|----------|----------|----------|
| 霸总 | 身份型 | → 直接走霸总赛道（自包含，无需读身份型总则） |
| 兵王 | 身份型 | → 走战神赛道，将"战神/龙王"换职业皮肤为"兵王/特种兵" |
| 神豪 | 身份型 | → 走战神赛道，爽点侧重财富碾压而非武力制霸 |
| 校园 | 场景叠加 | 先按主角金手指定型，校园作背景叠加 |
| 种田 | 成长型 | → 走逆袭赛道，金手指用写实型（祖传医术/农技/商业头脑） |
| 无限流副本 | 场景叠加 | 按主角驱动力定型，副本作背景叠加 |

> "按表套用" = 用映射目标赛道的完整框架（人设+结构+爽点），把皮肤/场景当作变量填入，不另起一套新规则。

## 4. 选题生成器框架（五维度组合法）

通用五维度，各赛道取值见对应展开节。用以下五维度拼接生成选题：

| 维度 | 说明 | 示例 |
|------|------|------|
| 1. 主角真实底牌/目标 | 隐藏的能力或身份目标 | 千亿总裁 / 前世记忆 / 系统商城 |
| 2. 起点困境/受辱设定 | 开局的压制状态 | 寿宴羞辱 / 被逼离婚 / 前世惨死闪回 |
| 3. 开局3秒钩子场景 | 第一幕的冲突画面 | "离婚！你这个废物赘婿！" |
| 4. 驱动动机 | 推动主角行动的核心动力 | 复仇 / 护家 / 改写命运 |
| 5. 冲突升级路线 | 反派/危机的递进链 | 势利亲戚→职场小人→幕后黑手 |

### 选题组合示例

| 赛道 | 维度1（底牌） | 维度2（困境） | 维度3（钩子） | 维度4（动机） | 维度5（升级） |
|------|-------------|-------------|-------------|-------------|-------------|
| 逆袭 | 隐世神医 | 寿宴被当众羞辱赶出门 | 岳母摔杯："滚出我林家！" | 护母复仇 | 势利亲戚→夺产→幕后推手 |
| 战神 | 退役龙王 | 为爱入赘三年被全家嫌弃 | 妻子递离婚协议："签字吧废物" | 守护女儿 | 家族→商业→江湖→国家 |
| 赘婿 | 隐世战神 | 三年之约将满，妻子被逼改嫁 | 婚礼现场被悔婚 | 三年之约赌约 | 家族看不起→女主被欺→幕后黑手 |
| 重生 | 前世记忆 | 前世被渣妻奸夫合谋害死 | 睁眼回到离婚当天 | 清算前世仇人 | 渣妻→奸夫→吸血亲戚→幕后主使 |
| 穿越A | 系统军火兑换 | 附身寒门少年，被恶霸欺凌 | 系统激活："首次兑换免费" | 制霸乱世 | 恶霸→贪官→藩王→外族 |
| 穿书B | 全本剧本记忆 | 穿成注定被天命之子斩杀的反派 | 原著主角当众挑衅 | 改写必死结局 | 天命方→天道→幕后操盘 |

## 5. 通用叙事风格（全赛道共享）

- 开局3秒钩子，1分钟内起冲突
- 快节奏、强冲突、情绪＞逻辑
- 竖屏画面感，桥段视觉高光
- 标签化人设、脸谱化反派
- 内核：先抑后扬，情绪螺旋上升

## 6. 成长型 — 人设详解

### 6.1 型核心

看点是**变强曲线**——观众追的是"他怎么一步步变强"。主角起点弱，由弱到强，循序渐进。

#### 型铁律：成长有依据

每一次变强都要有来源，不能凭空跳。合法来源：
- **机缘**（奇遇、传承、宝物）
- **苦修**（时间、代价、瓶颈突破）
- **顿悟**（关键节点的质变，但要有铺垫）
- **外力**（师门、贵人，但不能白给到破坏张力）

> 违反此律 = 爽点崩塌。跳级要付代价，突破要有铺垫。

#### 型结构特征

- 变强节点与冲突节点绑定：每上一个台阶，解锁一批新对手/新舞台
- 力量分级清晰，读者能感知"现在到哪一层了"
- 打脸建立在"实力刚好够/略微越级"上，不是碾压

---

### 6.1.1 逆袭赛道人设

> ⚠️ 逆袭含身份型"隐藏身份揭晓"元素，揭晓部分参考第7节身份型的揭晓时机管理。

**赛道定位**：成长型的"都市/现实翻身"子类，采用双层身份的扮猪吃虎框架。体量12-20集轻量快闭环，单集1-3分钟。

#### 专属人设

| 层次 | 内容 | 设计要点 |
|------|------|----------|
| 明面身份 | 受气赘婿/底层打工人/破产富二代/被排挤的废物少爷 | 贴现实困境，引共情 |
| 隐藏身份 | 千亿总裁/退役战神/隐世神医/修仙强者 | 埋打脸伏笔，能力与困境形成反差 |
| 反派 | 嚣张恶少/嫌贫爱富亲戚/背信弃义伙伴 | 作恶越狠打脸越爽 |
| 女主/助力 | 情感锚点或逆袭帮手 | 不抢戏不拖沓 |

#### 金手指分类（适配赛道）

| 类型 | 内容 | 适配场景 |
|------|------|----------|
| 奇幻型 | 系统/重生穿越/异能修仙/灵魂导师 | 都市奇幻变体 |
| 写实型 | 祖传医术/商业头脑/独特技艺 | 种田/都市现实变体 |

#### 选题维度取值

- **明面身份**：受气赘婿 / 底层打工人 / 破产富二代 / 废物少爷
- **隐藏身份**：千亿总裁 / 退役战神 / 隐世神医 / 修仙强者
- **金手指**：系统 / 重生穿越 / 异能 / 祖传医术 / 商业头脑
- **困境起点**：寿宴羞辱 / 家人被欺 / 事业破产 / 被爱人背叛
- **升级路线**：生存危机 → 势利亲戚 → 职场小人 → 资源争夺 → 终极反派
- **赛道变体**：都市奇幻 / 种田写实 / 都市现实

---

### 6.1.2 修仙赛道人设

**赛道定位**：成长型的"修真体系"子类。命门：设定自洽——世界观简单但绝不自相矛盾。体量20-50集。

#### 专属人设

**男主模板**（反套路优先，避免油腻）：

| 模板类型 | 设定 | 示例 |
|----------|------|------|
| 反套路逆袭型 | 大器晚成、系统迟到 | "穿越百年才激活系统，把老年劣势转成百年阅历" |
| 靠山加持型 | 国家背书/上古传承作后盾 | 个人逆袭升级为民族大义 |
| 设定反转型 | 把传统爽点反转成痛点 | "长生=眼看故人凋零的孤独" |

**配角配置**：
- 反派工具化：势利长老、背叛兄弟、碾压主角的天才
- 女主辅助型：提供机缘/解锁技能，弱化情感线

#### 金手指规则（设定自洽的核心）

- 金手指只讲"作用+限制"，不讲原理（如"任务解锁能力""沉睡五十年才能修炼"）
- 规则一旦设定，全程一致：设"废柴灵根不能修炼"，后期变极品必须有铺垫和原因
- 术语出场1句话解释完（"极品灵根修炼速度是普通10倍"）
- 建立**设定清单**（金手指规则/等级/势力关系），所有剧情围绕清单，杜绝前后矛盾

#### 选题维度取值

- **金手指**：迟到系统 / 双鱼玉佩国家支援 / 上古传承 / 不死体质
- **起点困境**：宗门弃子 / 底层矿奴 / 废柴灵根 / 濒死觉醒
- **反套路点**：大器晚成 / 国家背书 / 长生孤独 / 设定反转
- **升级路线**：宗门内斗 → 秘境夺宝 → 仙凡对立 → 家国大义

---

### 6.1.3 玄幻赛道人设

**赛道定位**：成长型的"奇幻战力体系"子类。命门：战力越级合规——低境界赢高境界必须有合规手段。体量标准60集。

结构口诀：**起—承—转—合—爆**。

#### 专属人设

- **男主**：废柴/赘婿/弃子开局，隐藏仙帝/神脉/系统/祖师身份。金手指开局即给、立刻能用，不藏不憋。
- **反派**：脸谱化、够嚣张、死得快，负责送经验、送脸打。
- **核心爽法**：扮猪吃虎 + 信息差碾压 + 越级反杀。

#### 世界观（轻量化）

只保留：**境界 + 灵根/武魂 + 宗门/家族 + 宝物/功法**。不搞复杂设定，观众一眼看懂战力高低。

视觉优先：斗法、破境、亮身份、神兽降世、神兵出鞘。

#### 战力越级合规机制（命门核心）

- 境界严格分级，低境界**不能随便**赢高境界
- 越级必须靠合规手段：**秘术 / 法宝 / 体质 / 阵法**，四选一给理由
- 战力成长线性可见，不突然无敌
- 金手指有代价、有冷却、有上限，能力"需要什么来什么"但不能提前乱给

#### 选题维度取值

- **隐藏身份**：仙帝 / 神脉 / 祖师 / 系统宿主
- **起点困境**：废柴 / 赘婿 / 弃子 / 被废修为
- **金手指**：开局即用型（系统 / 传承 / 神脉觉醒）
- **冲突升级链**：个人恩怨 → 宗门 → 地界 → 天界（层层升级不跳步）

## 7. 身份型 — 人设详解

### 7.1 型核心

看点是**揭晓时机**——观众追的是"他什么时候亮出真身份"。主角开局即巅峰，隐藏实力，扮猪吃虎。

#### 型铁律：不写成长，只管揭晓

- 主角实力从头到尾是满的，**不适用成长型"变强有依据"标准**
- 硬加修炼/升级会稀释"废物→大佬"的割裂反差，是错误做法
- 核心工程是"身份信息的释放节奏"

#### 揭晓时机管理

- **分寸感**：亮太早后续无爽点，亮太晚观众失耐心
- **卡点**：每次身份释放都卡在情绪最高点
- **误解维持**：小露锋芒后要被合理误解（运气/抱大腿），撑住悬念

#### 扮猪吃虎闭环

```
被轻视 → 隐忍 → 出手 → 反转 → 更高级轻视 → 更狠打脸
```

---

### 7.1.1 战神赛道人设

**赛道定位**：身份型的"归来型强者"子类。命门：一次性揭晓的时机（区别于赘婿的分层暴露）。体量60-80集，每集1.5-2.5分钟。

#### 专属人设

- **男主**：隐世战神/兵王/龙王/殿主，巅峰实力+顶级资源，却以赘婿/外卖员/小职员/弃子身份蛰伏受辱。
  - 核心设定："你不知道我厉害，但我其实无敌"——实力与身份极度割裂。
  - 属性：**隐忍 + 护短**。
- **反派**：脸谱化、嚣张、愚蠢刻薄，持续挑衅主角与家人，纯打脸工具。
- **配角**：势利眼亲友、忠心下属/大佬、被保护的女主，功能单一。

#### 选题维度取值

- **真实身份**：战神 / 兵王 / 龙王 / 殿主 / 神豪
- **底层伪装**：赘婿 / 外卖员 / 小职员 / 弃子
- **3秒羞辱**：离婚 / 悔婚 / 同学会嘲讽 / 夺产 / 家人被欺
- **隐退动机**：复仇 / 护家 / 夺权 / 隐秘任务
- **升级链**：个人恩怨 → 家族 → 商业 → 江湖 → 国家大义

---

### 7.1.2 赘婿赛道人设

**赛道定位**：身份型的"家庭聚焦"子类。冲突绑定婚姻家庭，护妻是情感锚点。

一句话：**先踩到底，再爽到炸**。

#### 专属人设

| 角色 | 设定 | 功能 |
|------|------|------|
| 男主 | 表面废物上门女婿、吃软饭、被全家看不起；真实战神/龙王/神豪/大佬/神医/继承人 | 隐忍、护妻、有仇必报、扮猪吃虎 |
| 女主 | 颜值高、能力强，半信半疑或默默维护 | 被欺负→触发护妻打脸 |
| 反派团（固定配置） | 势利丈母娘 / 嚣张小舅子 / 看不起人的亲戚 / 抢女主的富二代 / 商业对手 | 态度从看不起到巴结，转变本身就是爽点 |

#### 选题维度取值

- **真实身份**：隐世战神 / 龙王殿主 / 全球首富 / 商界大佬 / 绝世神医 / 隐世继承人
- **受辱起点**：被逼离婚 / 三年之约将满 / 为爱入赘遭嫌弃 / 契约婚姻被看轻 / 落魄被夺产
- **3秒钩子**：婚礼当众悔婚 / 家族会议被逐 / 同学会被嘲讽 / 离婚现场羞辱 / 女主被逼改嫁
- **隐忍动机**：为爱低调 / 三年之约赌约 / 履行长辈承诺 / 守护女主平静 / 隐秘任务
- **升级路线**：家族看不起 → 外人欺负女主 → 商业黑道搞事 → 幕后黑手

#### 组合示例

- 隐世战神 + 三年之约将满 + 婚礼悔婚 + 为爱低调 + 家族→幕后黑手
- 全球首富 + 落魄被夺产 + 女主被逼改嫁 + 履行承诺 + 商战线

### 7.1.3 霸总赛道人设

> 霸总为**自包含赛道**，通用身份型规则已并入，无需跳读其他文件。

**赛道定位**：男主对外是被轻视的普通人/落魄女婿/失忆病人，真实身份是隐藏的顶级豪门掌权人/资本巨鳄/神医富豪。

核心快感：**身份揭晓的打脸 + 资本降维碾压 + 护妻**。

与战神的本质区别：战神偏武力制霸，霸总偏**商战+财富碾压**，情感线权重更高，常带失忆追妻/双向隐忍变体。

#### 专属人设

| 角色 | 设定 |
|------|------|
| 男主 | 表层=木讷普通丈夫/上门女婿/失忆者/冷门职业（入殓师等）；真实=顶级金融财团继承人/资本操盘大佬/隐世神医，姐姐或家族在暗中兜底 |
| 女主 | 豪门千金/被迫与男主离婚/表面绝情实则被胁迫（双向隐忍） |
| 反派 | 势利岳父母 → 觊觎家产的男二/奸夫 → 策划车祸/吞并的真幕后 |

#### 选题维度

- **表层身份**：上门女婿 / 失忆丈夫 / 冷门职业者
- **隐藏身份**：金融财团继承人 / 资本操盘手 / 隐世神医（可叠加多马甲）
- **女主类型**：绝情离婚（实为被胁迫） / 豪门千金
- **情感结构**：失忆追妻 / 双向隐忍误会流 / 纯甜宠
- **反派链**：势利岳父母 → 觊觎家产男二 → 车祸吞并真幕后

## 8. 预知型 — 人设详解

### 8.1 型核心

看点是**认知碾压 + 改写命运**——观众追的是"主角知道未来/剧本，众人蒙在鼓里"的信息差。主角实力起点可高可低，核心武器是**信息**，不是拳头也不是身份。

#### 与另两型的区别

| 型 | 翻盘手段 | 核心看点 |
|----|---------|---------|
| 成长型 | 靠"变强" | 变强曲线 |
| 身份型 | 靠"亮身份" | 揭晓时机 |
| 预知型 | 靠"知道未来/剧本" | 信息差如何兑现和递减 |

#### 型铁律：预知必须"可兑现、会失效"

- 预知要转化成具体行动才有爽感（知道商机→提前买；知道阴谋→提前布证据）
- 信息优势必须随剧情递减：反派会变招、蝴蝶效应会让剧本偏移，逼主角用真本事补位
- 不能全程无脑开天眼，否则无张力

#### 型结构特征：改写既定悲剧

预知型几乎都有一条"原本的坏结局"作暗线：
- 重生：前世惨死/被夺产
- 穿书：原著里必死/灭门
- 穿越（降维）：附身对象原本被欺压至死/家族覆灭

主角全程在和"这个已知的坏结局"赛跑，改写它 = 最大爽点。

---

### 8.1.1 重生赛道人设

**赛道定位**：预知型的"前世记忆"子类。信息来源=主角上一世的完整经历。命门：前世记忆的兑现 + 改写前世悲剧。多为都市商战/家庭复仇。体量80集。

#### 专属人设

| 角色 | 设定 |
|------|------|
| 男主 | 前世惨死/被至亲背叛/家业被吞；重生回关键节点，一改前世懦弱恋爱脑，杀伐果断 |
| 反派 | 前世的加害者（渣妻、奸夫、吸血亲戚、渣男），恶行已通过前世闪回预知，打脸期待拉满 |
| 助力 | 青梅/真心人，事业情感双后盾 |

#### 选题维度取值

- **前世死因**：被配偶奸夫谋害 / 被合伙人背叛 / 被亲戚拖垮
- **重生节点**：离婚前 / 破产前 / 至亲遇害前
- **预知资产**：仇人阴谋链 / 贪腐证据 / 未来商机风口
- **改写目标**：保家业 + 护至亲 + 清算仇人
- **情感线**：青梅真心人（弱恋爱线，不狗血）

---

### 8.1.2 穿越赛道人设

> 本赛道含两个子型，命门不同，**分节填充，勿混用**。

---

#### 子型A：现代穿古代（降维流）

**定位**：信息来源 = 现代文明知识/科技代差。主角不知道异世剧本，靠"文明降维"碾压。命门：降维碾压的节奏 + 金手指的成本约束。

**样板**：《我带着现代武器制霸古代》

##### 专属人设

| 角色 | 设定 |
|------|------|
| 男主 | 现代普通人（代驾/工程师等），附身异世寒门/落魄少年，起点无权无势 |
| 金手指 | 系统兑换现代物资（武器/工业/药品），但**需靠经商赚银两解锁**，有成本门槛 |
| 反派 | 地方恶霸 → 贪官 → 割据藩王 → 朝廷奸臣 → 外族，**逐级升级** |

##### 金手指约束规则

- 金手指不能免费无限，必须"赚钱 → 解锁 → 更强"形成循环
- 每次升级要有对应的经济成本或任务门槛
- 解锁顺序有逻辑：先民生日用再军工重器

##### 选题维度

- **穿越身份**：寒门少年 / 落魄书生 / 戍边小兵
- **金手指类型**：军火兑换 / 工业图纸 / 全能商城
- **争霸目标**：割据一方 / 一统乱世 / 抗外族
- **治理线**：经商 + 军改 + 民生（体现现代思维）

---

#### 子型B：穿书（剧本流）

**定位**：信息来源 = 原著小说上帝视角。主角精确知道剧本、机缘、阴谋、死亡节点。命门：截胡剧本 + 改写必死结局 + 蝴蝶效应。

**样板**：《我这个反派强得离谱》《这大哥怎么不按剧本走》

##### 专属人设

| 角色 | 设定 |
|------|------|
| 男主 | 现代读者穿成原著里"注定败亡的角色"（反派大少/恋爱脑工具人大哥） |
| 天命方 | 原著主角/天命之子（如林萧），表面励志实则被剧本加持 |
| 女主/亲人 | 原著里的悲剧受害者（黑化真千金/受虐妹妹），主角改写其命运 |

##### 选题维度

- **穿书身份**：注定被斩的反派 / 被灭门的豪门大哥 / 工具人
- **已知信息**：全本机缘 + 阴谋 + 死亡节点
- **改写目标**：保命 + 护亲人 + 反杀天命方
- **幕后真相**：天道棋子论 / 资本安插棋子论

# 结构框架

> 本文档覆盖：通用结构骨架 → 单集公式 → 情绪节拍 → 各赛道专属阶段结构表。生成分集大纲时，找到对应赛道的结构表直接套用。

---

## 1. 通用结构骨架（60-100集，除逆袭外）

| 阶段 | 大致集数 | 作用 |
|------|----------|------|
| 开局炸场 | 1 | 3秒钩子，立冲突立人设 |
| 铺垫积累 | 2-10 | 小冲突+小高光，攒情绪 |
| 第一次高潮 | 10-20 | 首次大反转/打脸 |
| 中期扩张 | 20-40 | 冲突升级，格局扩大 |
| 全面高潮 | 40-60 | 核心爽点集中释放 |
| 终极闭环 | 60+ | 最终BOSS，圆满收束 |

> 各赛道在此骨架上填自己的阶段内容，见下文各赛道专属结构。

---

## 2. 单集万能公式

```
钩子 → 冲突升级 → 主角出手 → 反转 → 结尾悬念
```

### 2.1 逆袭赛道专属：单集黄金5步（约2分钟）

| 步骤 | 时长 | 内容 |
|------|------|------|
| 开篇 | 30秒 | 回顾上集亮点，衔接不脱节 |
| 推进 | 40秒 | 冲突升级，反派挑衅/新困境 |
| 核心 | 30秒 | 爽点爆发，金手指/隐藏实力即时翻盘 |
| 结尾 | 15秒 | 抛新危机/秘密/悬念留钩 |
| 预留 | 5秒 | 预留广告衔接位 |

---

## 3. 情绪循环节拍

```
压抑 → 释放 → 再压抑 → 再释放（螺旋上升，一次比一次狠）
```

通用原则：
- 每次释放的力度比上次大
- 两次释放之间给观众"喘气"的间隙（家庭温情/日常互动等）
- 大高潮前设压抑极值——越压抑，释放越爽

---

## 4. 付费点设计原则

- 卡点设在情绪最高/悬念最强处
- 每个付费段落自带一次小反转或爽点
- 大高潮前设钩子，诱导继续
- 战神赛道特殊：第9集结尾设强悬念（"你到底是谁？"），第10集揭晓卡在付费点

## 5. 成长型 — 赛道专属结构

### 5.1 逆袭赛道结构（12-20集，三段式闭环）

| 阶段 | 集数 | 填充内容 |
|------|------|----------|
| **开局压抑** | 1-3（黄金留人期/生死线） | 极致困境（寿宴羞辱/家人被欺/破产/背叛）+ 曝弱势身份 + 埋金手指伏笔；第3集尾第一钩子（金手指初激活/立誓） |
| **中期逆袭** | 4-15（爽感密集期） | 解生存危机 → 打脸小反派 → 积累资源升实力；冲突从个人恩怨升到资源争夺；每集尾留钩，"解决一个困境出现一个新挑战"循环 |
| **结局闭环** | 16-20（情绪收尾期） | 终极身份曝光/金手指终极能力 → 碾压终极反派 → 解决所有困境 → 情感闭环或价值升华 → 轻微伏笔或圆满收尾 |

---

### 5.2 修仙赛道结构（20-50集，示例按30集）

| 阶段 | 集数 | 填充内容 |
|------|------|----------|
| **铺垫期** | 1-10 | 1-2集立惨（弃子/矿奴被欺）；3-5集获金手指+首次小逆袭；6-8集引核心反派定冲突；9-10集首次重大危机化险+留钩 |
| **升级期** | 11-20 | 11-14实力提升解小麻烦；15-17宗门大比正面打脸；18-19秘境/仙凡冲突拓格局；20集入秘境/揭身世之谜留强悬念 |
| **高潮结局** | 21-30 | 21-25终极机缘+补全伏笔；26-28终极对决（劣势→绝境反击→碾压）；29解冲突达成目标；30留续集钩子或传正向价值观 |

### 5.3 玄幻赛道结构（60集，起承转合爆）

| 阶段 | 集数 | 填充内容 |
|------|------|----------|
| **起·开局绝境** | 1-5 | 被羞辱/退婚/废修为 → 濒死觉醒 → 首次小打脸，明确复仇/变强/守护目标 |
| **承·新手崛起** | 6-20 | 家族/宗门内斗，打脸同辈、展露天赋、获第一个机缘（受辱→蓄力→爆发→打脸→悬念） |
| **转·中期扩张** | 21-40 | 外出历练/秘境寻宝/拍卖会装杯，遇更强反派、团队成型（打小怪→爆装备→升境界→再打脸） |
| **合·高潮反转** | 41-55 | 大反派逼杀 → 绝境亮底牌 → 全场震惊 → 势力臣服，埋长线（身世、神界恩怨、宿敌） |
| **爆·结局登顶** | 56-60 | 斩大BOSS → 称霸一方 → 留第二季钩子，不写完全圆满 |

## 6. 身份型 — 赛道专属结构

### 6.1 战神赛道结构（60-80集）

| 阶段 | 集数 | 填充内容 |
|------|------|----------|
| **开篇钩子** | 1 | 3秒极致屈辱（"离婚！你这个废物赘婿！""敢动我老婆，找死！"）+ 全集全面打压 |
| **压抑铺垫** | 2-5 | 反派升级威胁家人；主角暗秀小露锋芒，被当成"运气好/抱大腿" |
| **小试牛刀** | 6-9 | 百亿项目/绑架/吞并等重大危机；被迫动用部分实力震惊众人，身份仍保密；第9集尾强悬念"你到底是谁？" |
| **身份揭晓** | 10 | 🔥军团跪呼 → 亮身份 → 权财武三重碾压 → 反派求饶（全剧最强爽点，卡付费点） |
| **中期扩张** | 11-40 | 复仇/夺权/护家/揭过往；商战权谋江湖多线并行（每5集小高潮，每10集大反转） |
| **后期决战** | 41-60 | 幕后黑手/当年仇敌登场，武力权力财力全面对决，多次反转 |
| **结局** | 61-80 | 大仇得报、功成名就、圆满收尾、伏笔回收 |

| **身份逐步暴露** | 20-40 | 老部下认主、神医喊主人；丈母娘小舅子又怕又想巴结 |
| **全面逆袭** | 40-60 | 真身曝光 → 看不起他的人道歉跪舔被清算 → 女主彻底沦陷 |
| **终极闭环** | 60+ | 幕后黑手现身 → 武力+财力+权力三重碾压 → 男主登顶、家族臣服 |

# 男频短剧编剧 Skill

## 用途
- **输入**：一个原创需求，或一部待判定的小说/设定
- **输出**：型判定 → 赛道选择 → 分阶段剧情大纲（阶段/分集节拍/爽点分布/关键节点）+ 审稿清单
- **不负责**：成稿正文、逐场台词。台词模板是"零件"，不是成品。

> 天花板是"分集大纲/桥段"层。不要用本 skill 硬写长文正文，否则会被"极简逻辑/情绪＞逻辑"口诀带偏成空洞套路。
> 标签/集合/爽点口号（回滚王子、两位王子、最优解、联猎）可写在大纲散文，**勿抽成 CHAR.name**。

---

## 使用流程

```
输入需求 → 型判定 → 皮肤映射 → 赛道定位 → 读对应 references 章节 → 套结构生成大纲 → 过审稿清单
```

### Step 1：读需求或原著特征
提取主角起点、核心金手指、冲突类型。

### Step 2：型判定
用 `references/ticai-yurenshe.md` 第1节的**型判定表**，归入：
- **成长型** — 看点：变强曲线（逆袭/修仙/玄幻）
- **身份型** — 看点：揭晓时机（战神/赘婿/霸总）
- **预知型** — 看点：信息差兑现（重生/穿越）

判定口诀：*"看他怎么变强"→成长型；"看他何时亮身份"→身份型；"看他怎么用预知改命"→预知型。*

### Step 3：皮肤/场景映射
查 `references/ticai-yurenshe.md` 第2节**皮肤映射表**。若是热门叫法（兵王/神豪/种田等），按表映射到对应赛道，不单独建模。

### Step 4：赛道定位
查 `references/ticai-yurenshe.md` 第3节**赛道细分+路由表**，锁定具体赛道。

### Step 5：读取 references 对应章节

| 需求 | 读取文件 | 定位章节 |
|------|---------|---------|
| 人设/金手指/反派设计 | `ticai-yurenshe.md` | 该型→该赛道的展开节 |
| 阶段结构/集数体量/单集节奏 | `jiegou-kuangjia.md` | 该型→该赛道的专属结构表 |
| 爽点类型/付费卡点/节奏编排 | `shuangdian-sheji.md` | 该型→该赛道的爽点配置 |
| 审稿口诀/反面清单/命门校验 | `luoji-jiaoyan-qingdan.md` | 通用清单 + 型清单 + 赛道清单 |

### Step 6：套结构生成大纲
按该赛道的专属结构表（`jiegou-kuangjia.md`）填充分阶段大纲，标注爽点位置和付费卡点。

### Step 7：过审稿清单
按 `luoji-jiaoyan-qingdan.md` 依次排查：通用清单 → 型审稿口诀 → 赛道反面清单 → 命门校验。

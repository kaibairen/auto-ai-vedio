## Char count (frozen)

`unicodedata.normalize("NFC", text.strip())` then **code-point `len`**. Internal spaces count. Draft `chars` = title + body **without** `［标题］` / `文案内容：` labels. A≤400; B≤500.

## REST

Prefix: `/api/v0/projects/{project_id}/episodes/{ep}`

| Method | Path | Notes |
|--------|------|--------|
| PUT | `nodes/n1/raw` | raw text |
| POST | `n1/sessions` | `{path, provider, reset}` → 201 |
| POST | `n1/steps/{step}/submit` | step ids: `a1_raw`…`a5_finalize` / `b1_raw`…`b6_finalize` |
| PUT | `nodes/n1/draft` | unlocked only; **409 locked** after G1 |
| GET | `nodes/n1` | `?view=session\|artifact\|full` authoring |
| GET | `n1/artifact` | **downstream**; **409** `upstream_unlocked` if not locked |
| POST | `gates/g1/confirm` | `{decision\|result\|action: pass\|reject, actor}` sole lock |

Aliases: `PUT/GET /n1/draft`, `GET /n1`. **No** `POST /n1/lock`. Body `force:true` → 400.

Envelope:

```json
{ "ok": true, "episode_id": "EP01", "node": "N1", "session": {}, "artifact": {}, "next_edges": [] }
```

Errors: `{ "ok": false, "error": { "code": "step_order|chars_limit|locked|upstream_unlocked|validation", "message": "", "details": {} } }`

`next_edges` after pass: `{to: writer|n2, requires: [pipeline_profile], provisional: true}`.

```bash
aiv n1 gate g1 --ep EP01 --decision pass --actor bot:demo
# downstream before lock → exit 3 / 409 upstream_unlocked
```

PRD alias: `aiv gate confirm --ep EP01 --gate g1 --result pass --actor bot:demo`.

Path B: after `b2_analyze`, `current_step=b3_skipped`; submit `{ack_defect:true}` then `b4_titles`…`b6_finalize`.

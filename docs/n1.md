# N1 口播定稿 runtime

Minimal in-repo runtime for **N1 only** (BRIEF-AIV-008). No 编剧, no N2–N6, no Seedance, no ForcePass.

Prompt sources are **read-only**:

- Path A: `.prompt/koubo-口水话.md` (steps 1–5, ≤400 字)
- Path B: `.prompt/koubo-长文章.md` (steps 1, 2, **skip 3**, 4–6, ≤500 字)

Path B’s missing step 3 and garbled frameworks 7/8 stay in the curriculum file. The wizard **skips** step 3 and does **not** rewrite the prompt.

## Install

```bash
python3 -m pip install -e ".[dev]"
```

Default LLM is **fixture mode** (`AIV_LLM_PROVIDER=fixture`). No API key required.

Optional real model:

```bash
export AIV_LLM_PROVIDER=openai
export AIV_OPENAI_API_KEY=...
export AIV_OPENAI_BASE_URL=https://api.openai.com/v1   # optional
export AIV_OPENAI_MODEL=gpt-4o-mini                    # optional
```

If the key is missing, the runtime stays on fixture.

Workspace files go under `$AIV_DATA_DIR` (default `./data`):

```
data/projects/{project_id}/episodes/EP01/
  N1-口播定稿.md          # SoT artifact (YAML frontmatter)
  .aiv/n1-session.json    # session machine (do not commit)
  .aiv/raw.txt
  .aiv/episode.json
```

## One-shot fixture demo

```bash
export AIV_DATA_DIR=./data
aiv n1 demo --project demo --ep EP01 --path A
# or --path B  (walks 1→2→4→5→6, never step 3)
```

This walks every legal step, writes `N1-口播定稿.md`, then locks via **G1 pass**. JSON is printed to stdout (bot-friendly). After lock it does **not** start 编剧; `next_edges` are `blocked` because **D2** is unset.

Human equivalent: `aiv serve` then open `/` (single-step wizard). Same REST as the CLI.

## REST (v0)

Prefix: `/api/v0/projects/{project_id}/episodes/{ep}`

| Method | Path | Role |
|--------|------|------|
| POST | `/episodes` | create `EP##` dir |
| POST | `/n1/sessions` | `{path: A\|B, provider: fixture\|openai}` |
| POST | `/n1/steps/{step}/submit` | one step only; body: `text`, `confirm`, `notes`, `frameworks[]`, `pick`, `title` |
| PUT | `/n1/draft` | write unlocked 定稿 |
| GET | `/n1` | authoring view (session/step/candidates JSON) |
| GET | `/n1/final` | **downstream** read; **409** if `locked=false` |
| GET | `/n1?consumer=downstream` | same 409 rule |
| POST | `/gates/g1/confirm` | **sole lock**: `{decision: pass\|reject, actor, notes?}` |

There is **no** `POST .../n1/lock` and **no** `force_pass`. Sending `force_pass` on confirm returns `400 force_pass_forbidden`.

### Session JSON (bot contract)

`GET /n1` and every submit/confirm response include:

```json
{
  "session_id": "uuid",
  "path": "A",
  "state": "stepping|awaiting_gate|locked",
  "current_step": 2,
  "allowed_steps": [2],
  "completed_steps": [1],
  "skipped_steps": [],
  "step_spec": {
    "step": 2,
    "kind": "analyze",
    "label": "...",
    "accepts": ["confirm", "notes"]
  },
  "candidates": [{"index": 0, "title": "", "body": "", "chars": 0, "framework": ""}],
  "draft": {"title": "", "body": "", "chars": 0, "framework": ""},
  "gate": {"id": "g1", "status": "pending", "confirm_path": ".../gates/g1/confirm"},
  "next_edges": [],
  "prompt_source": ".prompt/koubo-口水话.md",
  "char_limit": 400,
  "locked": false
}
```

Path B after step 2: `allowed_steps: [4]`, `skipped_steps: [3]`. Submitting step 3 → `400 source_defect_skip`.

## How a bot drives G1

1. `POST /n1/sessions` with `path` + `provider: fixture` (or `openai`).
2. Loop: read `allowed_steps` + `step_spec.accepts`; `POST /n1/steps/{step}/submit` with only that step’s fields. Never batch steps.
3. Optional: `PUT /n1/draft` to edit the 定稿 (still unlocked).
4. **G1**: `POST /gates/g1/confirm` with `decision=pass` and `actor` (copied to YAML `confirmed_by`).
5. Downstream nodes must `GET /n1/final`. If `locked=false` they get **409** `n1_not_locked`.
6. After pass, read `next_edges` (writer / n2) — both `blocked` until D2 / `pipeline_profile` is set. Do not call writer APIs; they are not implemented.

CLI form of the same lock:

```bash
aiv n1 confirm --project demo --ep EP01 --decision pass --actor bot:ci
```

Reject (optional `rollback_to` step):

```bash
aiv n1 confirm --project demo --ep EP01 --decision reject --actor bot:ci --rollback-to 2
```

## Artifact frontmatter

```yaml
---
node: N1
path: A
framework: 惊喜揭秘型
chars: 86
source_ref: .aiv/raw.txt
confirmed_by: bot:demo
locked: true
version: 1
---
```

Editing a locked draft via `PUT /n1/draft` does `version++` and clears `locked` (must G1 again). No silent reuse.
